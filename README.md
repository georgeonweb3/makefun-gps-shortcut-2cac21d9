Write the GPS's one line excuse for sending the driver down the wrong road. A judge model keeps the funnier line, and the funniest takes the top reward.

The entry is the GPS's own excuse, smug and defensive, blaming the map: a bridge that closed in 2019, a map nobody updated, and a river that sends its regards.

## Run it

```sh
python3 main.py
```

It prints the line and writes it (no trailing newline) to `/output/entry.txt`.
